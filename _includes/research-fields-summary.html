{%- comment -%} Fields of research summary, generated from every page with type: "BioShell Research". Each project lists up to three ANZSRC 2020 FoR codes in front matter: fields_of_research: [3108, 3105, 3102] A project counts once for every field it lists, whatever its position — primary, secondary and tertiary are not distinguished. Fields are listed most common first (ties in code order), as a bar scaled to the most common field. Names come from _data/anzsrc_for.yml; a code missing there is shown as "ANZSRC ". Like research-stats.html, values are collected into ","-separated strings and then split, because Liquid has no way to push onto an array. Sorting uses a key of (1000 - count, as 3 digits) followed by the code, so a plain ascending sort puts the highest counts first. {%- endcomment -%} {%- assign research = site.pages | where: "type", "BioShell Research" -%} {%- assign tagged = 0 -%} {%- assign all_codes = "" -%} {%- for project in research -%} {%- if project.fields_of_research -%} {%- assign tagged = tagged | plus: 1 -%} {%- assign seen = "|" -%} {%- for raw in project.fields_of_research -%} {%- comment -%} Tolerates 3108, "3108" and "3108 Plant biology". {%- endcomment -%} {%- assign code = raw | append: "" | strip | slice: 0, 4 -%} {%- assign key = "|" | append: code | append: "|" -%} {%- unless seen contains key -%} {%- assign seen = seen | append: code | append: "|" -%} {%- assign all_codes = all_codes | append: code | append: "," -%} {%- endunless -%} {%- endfor -%} {%- endif -%} {%- endfor -%} {%- assign all_list = all_codes | split: "," -%} {%- assign unique_codes = all_list | uniq -%} {%- assign sort_keys = "" -%} {%- assign max_count = 0 -%} {%- for code in unique_codes -%} {%- assign n = 0 -%} {%- for c in all_list -%}{%- if c == code -%}{%- assign n = n | plus: 1 -%}{%- endif -%}{%- endfor -%} {%- if n > max_count -%}{%- assign max_count = n -%}{%- endif -%} {%- assign inverse = 1000 | minus: n | prepend: "000" | slice: -3, 3 -%} {%- assign sort_keys = sort_keys | append: inverse | append: code | append: "," -%} {%- endfor -%} {%- assign sorted_keys = sort_keys | split: "," | sort -%} {%- if tagged > 0 -%}
